## Project Description
This is a simple Java console application that allows users to enter student details and subject marks. The program calculates the maximum mark, total marks, average, and displays whether the student has passed or failed through a menu-driven interface.

## Features
- Enter Student Index Number
- Enter Student Name
- Enter Number of Subjects
- Input Marks for Each Subject
- Display Student Details
- Display Maximum Marks
- Calculate Total Marks
- Calculate Average Marks
- Display Pass/Fail Result
- Menu-Driven Program
- Exit Option

## Technologies Used
- Java
- Scanner Class
- Loops (for, while)
- Switch Case
- Conditional Statements (if-else)

## How to Run
1. Open the project in IntelliJ IDEA or any Java IDE.
2. Compile the `Stud.java` file.
3. Run the program.
4. Enter the required student details and marks.
5. Select options from the menu to view results.

## Sample Menu

```
A. Display Student Details
B. Display Maximum Marks
C. Display Total, Average & Result
X. Exit
```
